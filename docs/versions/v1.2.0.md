- AI Arena with three autonomous agents.
- Streamlit 1.54.0, PyArrow 23.0.1, pytest 9.0.3 security update.
- NumPy 2.2.6 / SciPy 1.15.3, compatible with Python 3.10–3.13.

- 248 tests on Python 3.10, 3.11, 3.12, and 3.13.
- 85% coverage, 80% CI gate.
- CodeQL: 0 open alerts.
- Dependabot: 0 open alerts.

## Known constraints

- Option chains are synthetic and educational.
- Basis convergence is idealized.
- LLM prose is not investment advice and falls back locally on failure.
